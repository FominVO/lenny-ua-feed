# Lenny UA — озвучки

Український подкаст-конспект епізодів [Lenny's Podcast](https://www.lennysnewsletter.com) (Lenny Rachitsky). Повністю згенерований AI: сценарій українською + озвучка. Неофіційний проєкт Владислава Фоміна (Vladyslav Fomin) для особистого прослуховування.

Медіафайли лежать у [релізі v1](https://github.com/FominVO/lenny-ua-feed/releases/tag/v1). Фіди мають `itunes:block`, тож шоу **немає в каталозі Apple Podcasts** — додавати лише за URL RSS.

## RSS-фід

```
https://raw.githubusercontent.com/FominVO/lenny-ua-feed/main/feed.xml
```

Скопіюйте цей URL повністю й вставте в застосунок (див. нижче).

## Як підписатися

### Apple Podcasts (iPhone / iPad)

1. Відкрийте програму **Подкасти**.
2. Вкладка **Медіатека**.
3. Кнопка **⋯** (праворуч угорі) → **Відстежувати шоу за URL** (*Follow a Show by URL*).
4. Вставте URL фіду → **Стежити**.

### Apple Podcasts (Mac)

1. Відкрийте програму **Подкасти**.
2. Меню **Файл** → **Відстежувати шоу за URL** (*File → Follow a Show by URL*).
3. Вставте URL → **Стежити**.

### Pocket Casts

1. Вкладка **Discover** або **Podcasts** → іконка пошуку.
2. Вставте URL фіду в поле пошуку й підтвердіть.
3. Відкрийте шоу → **Follow**.
4. Якщо список епізодів застарів — потягніть екран униз (pull to refresh) або видаліть і додайте фід знову.

Альтернатива: [відкрити фід у Pocket Casts Web](https://pocketcasts.com/follow/https://raw.githubusercontent.com/FominVO/lenny-ua-feed/main/feed.xml) і натиснути Follow.

### Overcast (iOS)

1. Кнопка **+** (праворуч угорі).
2. **Add URL**.
3. Вставте URL фіду → **Add**.

### Castro (iOS)

1. Вкладка **Search**.
2. Вставте URL фіду в рядок пошуку.
3. Відкрийте результат → **Subscribe**.

### AntennaPod (Android)

1. Меню **⋯** → **+ Add Podcast** (або бічне меню → **+ Add Podcast**).
2. Додайте подкаст за RSS-адресою.
3. Вставте URL → підтвердіть.

### Podcast Addict (Android)

1. Кнопка **+**.
2. **RSS feed** (або Add a podcast → RSS feed URL).
3. Вставте URL → **Add**.

## Нотатки

- Шоу **немає в каталозі Apple** і в пошуку більшості додатків — додавайте **лише за URL**.
- Після оновлення фіду зробіть **pull to refresh** у застосунку. Якщо нових епізодів не видно — видаліть підписку й додайте URL знову.
